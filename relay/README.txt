آن لائن ریلے لگانے کا آسان طریقہ (صرف ایک بار، صرف براؤزر سے، مفت)
1. dash.cloudflare.com پر مفت اکاؤنٹ بنائیں۔
2. Workers & Pages ← Create ← Import a repository (Connect to Git) ← GitHub کو اجازت دیں ← clinic-app چنیں۔
3. Root directory میں: relay   (باقی سب جوں کا توں) ← Deploy۔
4. کچھ دیر میں پتہ ملے گا: https://clinic-relay.xxxx.workers.dev — وہ مجھے بھیج دیں۔ میں اسے ایپ میں ہمیشہ کے لیے شامل کر دوں گا، پھر کسی صارف کو کچھ نہیں کرنا۔
(وقتی طور پر پتہ ایپ میں ترتیبات ← PC سے رابطہ ← «آن لائن ریلے کا پتہ» میں بھی لکھ سکتے ہیں۔)
ڈیٹا AES انکرپٹ ہو کر جاتا ہے؛ ریلے اسے پڑھ نہیں سکتا۔ ہر کلینک کا الگ خفیہ ڈبہ (ٹوکن سے) ہوتا ہے۔ PC چالو ہونا ضروری ہے۔
اگر Durable Objects نہ چلے تو worker-kv.js (سادہ ورژن) بھی موجود ہے۔
